# 개발 도구 추가 후보 검토 (2026-11-27)

Git 창 `도구` 판에 이미 넣은 것: 탐색기, VS Code, 새 터미널 탭, 저장소 웹, `package.json` 명령, `.env` 빠진 키, 열린 포트.
아래는 그 밖에 넣을 수 있는 후보임. 구현하지 않았고, 효용과 비용만 정리함.

| 후보 | 하는 일 | 효용 | 비용·위험 | 권장 |
| --- | --- | --- | --- | --- |
| 스태시 목록·적용 | `git stash list/push/pop` | 브랜치 전환이 막힐 때(변경 있음) 바로 해결 | 작음. pop 충돌 시 안내 필요 | 1순위 |
| 변경 되돌리기 | 파일 하나 `git restore` | 실수한 수정 취소 | 데이터 손실 가능 → 확인 창 필수 | 2순위 (확인 창 포함) |
| 커밋 되돌리기(revert)·태그 | `git revert`, `git tag` | 배포 작업 | 원격에 영향 → 푸시와 같은 확인 필요 | 보류 |
| MR·PR 만들기 | `gh pr create`, GitLab API `POST merge_requests` | 브랜치 푸시 후 바로 리뷰 요청 | API 쓰기 권한 필요(GitLab 토큰 범위 확인), 입력 칸 많음 | 2순위 |
| CI 로그 마지막 줄 | `gh run view --log-failed`, GitLab job trace | 실패 원인을 창에서 바로 확인 | 로그가 큼 → 마지막 N줄만 | 3순위 |
| 포트 점유 프로세스 종료 | `taskkill /PID` | 개발 서버 재시작 때 포트 충돌 해결 | 시스템 프로세스 종료 위험 → 이 폴더에서 띄운 것만, 확인 창 | 보류 |
| Docker 컨테이너 상태 | `docker ps` (이 PC에서 MES 개발 환경이 Docker 사용) | 로컬 DB·서버 상태 확인 | Docker가 없으면 숨김 | 3순위 |
| 최근 셸 명령 | PowerShell 기록(PSReadLine) | 자주 쓰는 명령 다시 실행 | 기록에 비밀번호·토큰이 남아 있을 수 있음 → 화면 표시 위험 | 미권장 |
| 의존성 점검 | `npm outdated`, `npm audit` | 보안 경고 확인 | 실행이 느림(수십 초), 네트워크 필요 | 3순위 |
| 브랜치 만들기 | `git switch -c` | 작업 시작이 빨라짐 | 작음 | 1순위 |

판단 근거:
- 데이터를 지우거나 원격을 바꾸는 기능(되돌리기, revert, 프로세스 종료)은 확인 창 없이는 넣지 않음.
- 토큰·비밀 값이 화면에 나올 수 있는 기능(셸 기록, `.env` 값 표시)은 넣지 않음. `.env` 점검은 키 이름만 표시함.
