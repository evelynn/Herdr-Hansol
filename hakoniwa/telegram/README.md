# 텔레그램 원격 제어

휴대폰 텔레그램에서 Herdr 의 터미널 상태를 보고 버튼으로 승인·키 입력·빠른 지시·중단·종료를 합니다.
Hakoniwa 상단 바의 **원격** 버튼으로 켜고 끕니다.

## 설치

1. 이 폴더(`bot.mjs`)를 PC 의 한 폴더에 둡니다. 기본 위치는 `D:/VBOX/herdr-telegram` 이고, 다른 곳에 두려면 `mods/hakoniwa/remote.js` 의 `REMOTE_DIR` 을 바꿉니다.
2. 텔레그램 `@BotFather` 에서 `/newbot` 으로 봇을 만들고 토큰을 받습니다.
3. 같은 폴더에 `config.json` 을 만듭니다.
   ```json
   {"token":"<봇 토큰>"}
   ```
4. Hakoniwa 상단의 **원격 끔** 을 누르면 **페어링 123456** 처럼 번호가 보입니다.
5. 휴대폰에서 봇에게 `/pair 123456` 을 보내면 연결됩니다. 이후 그 대화에서만 명령을 받습니다.

Node.js 22 이상과 `hc`(herdr-core), `herdr-app` 이 필요합니다. 바깥으로 나가는 연결만 쓰므로 포트를 열 필요가 없습니다.

## 화면

- **현황**: 프로젝트(공간)별로 묶은 터미널 상태. 🟠승인 대기 🔵작업 중 🟢완료 ⚪대기 ⚫셸
- **터미널**: 상태와 최근 화면, 승인·거절 또는 Enter·Esc·중단, 빠른 지시, 더보기(방향키·Ctrl+C·종료 등)
- **글 입력**: 지금 열린 터미널에 입력하고 Enter
- **알림**: 승인 대기·작업 완료

최신 정보만 처리합니다. 화면 메시지는 늘 1개만 남고, 지난 메시지의 버튼과 봇이 꺼져 있던 동안 보낸 명령은 실행하지 않습니다.
60초가 넘은 화면의 조작 버튼은 새로 고침부터 하고, 승인은 그 순간에도 승인 대기일 때만 실행합니다.

빠른 지시 목록은 `config.json` 의 `"presets": ["계속 진행해 줘", ...]` 로 바꿉니다.

## 보안

터미널 화면 내용이 텔레그램 서버를 거칩니다. `config.json`(토큰)은 커밋하거나 공유하지 마세요.

## 검증

```
node verify-bot.mjs
```
가짜 텔레그램 서버로 페어링·현황·관리 화면·지난 메시지 무시·종료를 확인합니다(시험용 셸을 하나 만들고 지웁니다).
